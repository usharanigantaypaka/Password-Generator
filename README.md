# Password-Generator
## Description
A simple GUI-based Python application that generates secure random passwords based on user-selected options.

## Features
- Generate strong passwords
- Choose password length
- Select uppercase, lowercase, numbers, and symbols
- Password strength indicator
- Copy password to clipboard
- View last 5 generated passwords

## Technologies Used
- Python
- Tkinter
- Secrets
- Pyperclip

## How to Run
1. Install `pyperclip`.
2. Run `password_generator.py`.
3. Generate your password using the GUI.
